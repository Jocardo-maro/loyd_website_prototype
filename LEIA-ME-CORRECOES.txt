LOS DEVS — CORREÇÕES DE CAMINHOS PARA GITHUB PAGES

Este pacote mantém a estrutura de pastas do projeto e corrige os caminhos locais
para funcionar tanto no Live Server quanto no GitHub Pages em:
https://jocardo-maro.github.io/loyd_website_prototype/

O que foi corrigido:
- Links de CSS e JavaScript nas páginas.
- Caminhos de imagens, ícones, GIFs, vídeos e músicas.
- Navegação entre páginas.
- Caminhos de imagens usados pelo JavaScript.
- Imagem de fundo referenciada pelo CSS.
- Redirecionamento da página inicial da raiz.

COMO APLICAR:
1. Faça uma cópia de segurança da pasta atual do projeto.
2. Extraia este ZIP.
3. Copie o conteúdo da pasta "loyd_website_prototype_corrigido" para dentro
   da sua pasta atual "loyd_website_prototype", aceitando substituir os arquivos.
4. NÃO apague a pasta .git do seu projeto original. Ela não está incluída neste ZIP.
5. Abra o projeto no VS Code, teste com Live Server e depois faça commit + push.

Observação:
Os arquivos page/charactersdi.html, page/mapdi.html e page/socialsdi.html
estavam vazios no ZIP recebido; não foram inventados nem preenchidos.
